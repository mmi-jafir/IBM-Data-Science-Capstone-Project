This repository contains the **IBM Data Science Capstone Project**, the final course in the **IBM Data Science Professional Certificate** program offered on Coursera.

This capstone applies end-to-end data science methodologies to a real-world business problem involving **SpaceX Falcon 9 rocket launches**. The objective is to analyze historical launch data and build predictive models to estimate the likelihood of successful first-stage landings.

---

# Project Overview

SpaceX significantly reduces launch costs by recovering and reusing the Falcon 9 first stage. Predicting whether the first stage will land successfully is valuable for estimating launch costs and mission planning.

In this project, the role of a Data Scientist is simulated to analyze SpaceX launch records and develop predictive insights using data science techniques.

Key objectives include:

- Collecting SpaceX launch data
- Cleaning and preparing the dataset
- Performing exploratory data analysis
- Visualizing launch patterns and trends
- Building machine learning models
- Predicting first-stage landing outcomes

---

# Dataset

The project uses publicly available SpaceX launch data collected from:

- SpaceX REST API
- Wikipedia web scraping
- Structured datasets prepared for analysis

Data sources include mission details such as:

- Launch site
- Payload mass
- Booster version
- Orbit type
- Launch outcomes
- Landing success status

# Project Workflow

The project follows a complete data science workflow.

---

## Data Collection

Data was gathered from multiple public sources.

Tasks included:

- Collecting launch data using the SpaceX API
- Web scraping launch records from Wikipedia
- Combining structured datasets

---

## Data Wrangling

The collected data was cleaned and prepared.

Tasks included:

- Handling missing values
- Data transformation
- Feature engineering
- Formatting variables for analysis

---

## Exploratory Data Analysis (EDA)

Exploratory analysis was performed to identify trends and relationships.

Analysis included:

- Launch success distribution
- Payload vs launch outcome
- Orbit analysis
- Launch site comparisons
- Booster version analysis

---

## SQL Analysis

SQL queries were used to analyze structured launch data.

Tasks included:

- Filtering mission records
- Aggregating launch statistics
- Identifying launch site performance
- Summarizing payload and orbit patterns

---

## Interactive Visualization

Interactive visualizations were created to explore launch patterns.

Tools used:

- Plotly
- Folium
- Dash

Visualizations included:

- Interactive scatter plots
- Launch site dashboards
- Geographic launch maps
- Payload analysis charts

---

## Predictive Modeling

Machine learning models were built to predict landing success.

Models evaluated:

- Logistic Regression
- Support Vector Machine (SVM)
- Decision Tree Classifier
- K-Nearest Neighbors (KNN)

Evaluation techniques included:

- Accuracy comparison
- Model validation
- Hyperparameter tuning

# Key Findings

Key findings from the analysis include:

- Launch success rates improved significantly over time.
- Certain launch sites demonstrated consistently stronger performance.
- Payload mass influenced landing success probability.
- Orbit type and booster version impacted launch outcomes.
- Machine learning models successfully predicted landing outcomes with strong performance.
